# DawnDuskTerminal 晨昏线维度

Minecraft 1.21.1 NeoForge 模组 添加一个「晨昏线」维度 维度内没有昼夜更替 太阳高度由玩家坐标决定 世界被一条晨昏线切成昼侧与夜侧

> **本项目处于早期开发阶段**
>
> - 版本号 `0.1.0` 未发布正式版
> - 功能与数据结构仍在变动 存档随时可能不兼容
> - 未做完整测试 崩溃与地形异常都是正常现象
> - **硬依赖暮色森林** 未安装会在启动阶段直接拒绝加载
> - 请勿用于正式存档 请自备备份

# 第一部分 普通使用者

## 使用前必读

**模组硬依赖暮色森林** 对应 1.21.1 分支 缺了加载器会报缺失依赖

**维度内没有昼夜** 时间锁定在黄昏 睡觉只重置重生点

**太阳跟着坐标走** 往昼侧走太阳升高 往夜侧走太阳降低 同一服务器里两人位置不同各自的太阳高度也不同

**水就是传送门** 这个维度的水是传送门流体 碰到就会触发传送 所以别在海洋里游泳

**开启条件** 先在暮色森林击败九头蛇 暮色恶魂 冰雪女王三者之一

## 常见问题

**Q 进去之后出不来**
往回走进水里 或用传送指令

**Q 太阳不动**
太阳跟坐标走不跟时间走 你站着不动它就不动

**Q 为什么这么黑**
你在夜侧 往昼侧走会变亮

**Q 装了光影之后天空不对**
光影会盖掉本模组自绘的天空 不保证兼容

**Q 海洋里一走就传送**
刻意设计 水体即传送门 设计上无法在海洋里正常游泳

**Q 多人游戏里别人看到的天空不一样**
正常 每个人按自己的坐标算

**Q 地形有洞或穿模**
开发阶段 地形参数仍在调整 遇到异常请提交截图与坐标

# 第二部分 开发者

> **警告** 以下内容描述的是开发中状态 随代码变动 不保证与已发布版本一致

## 核心数据结构

| 结构 | 存什么 | 落点 |
|---|---|---|
| `ChronoLineState` | 晨昏线原点与法向 五档群系分界宽度 | 世界数据 |
| `ChronoBiomeSource` | 把到晨昏线的距离折进气候参数 | 群系源 |
| `YBand` | 按高度强制指定群系 | 群系源内 |
| `SideShift` | 昼侧夜侧的群系替换映射 | 群系源内 |
| `BossProgressTracker` | 三个 boss 的击败标记 | 玩家附件 |
| 密度函数 | 空岛与空置域的密度 | 数据包 json |

## 机制与判定

| 机制 | 判定方式 |
|---|---|
| 无昼夜 | `dimension_type` 锁 `fixed_time` |
| 太阳高度 | 玩家坐标在晨昏线法向上的投影 除 5000 乘最大角 |
| 群系分区 | 投影值 落进五档 |
| 按高度强制群系 | `y_bands` 优先于水平分区 |
| 昼侧夜侧群系替换 | `side_shift` 按投影正负选热侧或冷侧 |
| 传送触发 | 满足主动动作且冷却结束 |
| 防止弹回 | 回程落点固定 落点周围豁免建造判定 |
| 结构悬空避免 | 挖空放在洞穴阶段 结构在其后生成 |

## 地形生成要点

### 四层结构

| 层 | 高度 | 机制 |
|---|---|---|
| 地壳 | -64 以下 | `surface_rule` 垂直渐变铺 `peridotite` |
| 地下空岛 | -64 到 0 | `underground_island` 噪声加渐变 |
| 地表 | 0 到 176 | `mainland` 噪声加高原截断 |
| 天空空岛 | 176 以上 | `sky_island_density` 噪声加高度窗 |

`final_density` 取三者的最大值 再减去绝对噪声挖洞穴

### 关键参数

| 参数 | 值 | 说明 |
|---|---|---|
| `sea_level` | 62 | 海平面 |
| `default_block` | `sky_stone` | 默认填充方块 |
| `default_fluid` | `minecraft:air` | 必须是空气 设成水会灌满所有洞穴 |
| `aquifers_enabled` | false | 关闭含水层 |
| `ore_veins_enabled` | false | 关闭原版矿脉 否则会生成花岗岩安山岩 |

> **踩过的坑** `default_fluid` 若留默认值 `water` 配合 `sea_level: 62` 会把海平面以下所有洞穴灌满水 表现为「地下 100% 是水」看起来像实体
>
> **踩过的坑** `ore_veins_enabled` 留 `true` 时原版大矿脉会生成 `granite` `andesite` 与自定义岩石混在一起

## 逆向结论

| 结论 | 影响 |
|---|---|
| 上游传送门建造判定是 水 加 可种植方块 加 植物 加 投料 | 直接照抄判定顺序 |
| 上游群系按自己的地形高度铺特征 | 搬到空岛会悬空 需要高度修正或自建群系 |
| 天光烘焙进区块 | 改天光后老存档要重算 |
| 天空色按玩家所在群系插值 | 想精确渐变只能自绘天空 |

## 从源码构建

准备一份暮色森林 1.21.1 的 jar 放进 `libs/`

```
./gradlew build
```

产物在 `build/libs/`

开发期运行

```
./gradlew runClient
./gradlew runServer
```

> 首次构建会下载并反编译 Minecraft 约 1 到 2 分钟 首次 `runServer` 还会额外下载约 770MB 资源
